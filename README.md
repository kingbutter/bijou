# Bijou

*bijou* — what small-town movie houses were called before they were multiplexes.

An illuminated one-sheet display for the wall outside a home theater. It pulls
posters from a Plex library and rotates through them as **Coming Soon**, then
flips to **Now Showing** the moment something starts playing on the theater
client.

Designed for an old monitor mounted in portrait orientation, but it works on
anything with a browser.

## What it looks like

A chrome-bezelled lobby case: enamel header plaque, glass with a fixed diagonal
reflection, a billing strip underneath, and tungsten bulbs chasing round the
perimeter — slow and lazy while idle, faster once a film is playing. When the
poster changes the lamps dip, the image crossfades, and the lamps surge back up.

It's all CSS. Nothing is composited server-side and there are no frame images.

## Requirements

- A Plex Media Server
- Python 3.10 or newer — **that's the entire dependency list**, or Docker if
  you'd rather not install anything at all

No pip, no venv, no nginx, no PHP, no build step.

## Quick start

```bash
git clone https://github.com/OWNER/bijou.git
cd bijou
PLEX_HOST=192.168.1.10 PLEX_TOKEN=xxxx PLEX_SECTIONS=1 python3 app/bijou.py
```

Open <http://localhost:8080/>.

**Just want to see it?** `http://localhost:8080/?demo=1` rotates through six
original posters drawn in SVG — no Plex, no network. Works straight off the
filesystem too: open `app/static/index.html?demo=1` in any browser.

The demo art is generated by [`tools/gen_posters.py`](tools/gen_posters.py) and
inlined into the page. To change it, edit the poster functions and re-run:

```bash
python3 tools/gen_posters.py --preview     # writes PNGs to /tmp to eyeball
python3 tools/gen_posters.py               # prints the array to paste in
```

### Finding your values

Start Bijou and open **`/setup`** — it runs without a token precisely so this
page is reachable on a fresh install. It signs you in to
Plex with a code, lists your servers and libraries, and prints a config block to
paste into `.env` or `/etc/bijou.env`.

```
http://your-host:8080/setup
```

It writes nothing anywhere — the token passes through your browser and it's up
to you where it lands. That keeps the container `read_only` and the systemd
sandbox intact. Set `BIJOU_SETUP=0` to remove the page once you're configured.

<details>
<summary>Or find the values by hand</summary>

| Value | Where |
| --- | --- |
| `PLEX_TOKEN` | Any library item → ⋯ → Get Info → View XML, then copy `X-Plex-Token` from the URL |
| `PLEX_SECTIONS` | `http://PLEX_HOST:32400/library/sections?X-Plex-Token=...` — the `key` of your movies library |
| `PLEX_CLIENT_MATCH` | The IP or name of the player by the display. Leave empty to react to any playback. |

</details>

**If Plex runs in Docker.** Plex advertises whatever addresses it can see on
itself, which inside a container means the bridge IP (`172.17.0.x`) — flagged
"local" but unreachable from anywhere else. `/setup` tests every advertised
address from the machine Bijou is on and labels each one, so just pick a
`reachable` row, or type your server's LAN address into the box. Setting
**Settings → Network → Custom server access URLs** in Plex fixes it at the
source and is worth doing regardless.

**A note on picking the player.** Plex has no reliable "list every client"
endpoint — `/clients` only returns players that announce themselves over GDM
and accept remote control, so it's often empty even while something is
streaming. The setup page merges `/clients` with anything currently playing and
labels which is which, but the surest way to see your theater player is to
start a film on it first and then load `/setup`. Typing the IP by hand works
just as well.

## Docker

```bash
cp .env.example .env       # then edit it
docker compose up -d
```

Or without compose:

```bash
docker run -d --name bijou -p 8080:8080 \
  -e PLEX_HOST=192.168.1.10 \
  -e PLEX_TOKEN=xxxx \
  -e PLEX_SECTIONS=1 \
  --restart unless-stopped \
  ghcr.io/OWNER/bijou:latest
```

The image is `python:3.13-alpine` plus two files. It writes nothing to disk, so
it runs fine `read_only`.

## Bare metal

```bash
sudo ./deploy/install.sh
sudo nano /etc/bijou.env
sudo systemctl start bijou
```

Installs to `/opt/bijou`, runs as a `poster` system user under systemd
with a fairly tight sandbox. Re-run the script to update.

If the same machine also drives the monitor, see **[docs/NUC.md](docs/NUC.md)**
for the kiosk setup — a Wayland compositor and a browser, no desktop
environment.

## Display options

Both are query parameters on the URL, so you can test them in any browser
before committing them to a kiosk config.

| Parameter | Effect |
| --- | --- |
| `?rotate=90` | Turn the display a quarter turn. Also `180`, `270`. |
| `?poster=fill` | Crop artwork to the glass instead of fitting it inside. |
| `?demo=1` | Placeholder posters, no Plex needed. |

They combine: `?rotate=90&demo=1`.

## Configuration

Environment variables, all optional except the first three.

| Variable | Default | Notes |
| --- | --- | --- |
| `PLEX_HOST` | `127.0.0.1` | |
| `PLEX_TOKEN` | — | Required. |
| `PLEX_SECTIONS` | `1` | Library IDs, comma separated. Several get mixed together. |
| `PLEX_PORT` | `32400` | |
| `PLEX_HTTPS` | `0` | Set `1` if your server needs it. |
| `PLEX_CLIENT_MATCH` | *(empty)* | Substring match on the player's IP **or** name. Empty means any playback counts. |
| `BIJOU_SELECTION` | `unwatched` | Also `all` or `recent`. |
| `BIJOU_RECENT_TAKE` | `40` | How many, when `recent`. |
| `BIJOU_ROTATE_SECONDS` | `30` | How long each poster stays up. |
| `BIJOU_SESSION_POLL` | `3` | How often the server asks Plex what's playing. |
| `BIJOU_QUEUE_REFRESH` | `1800` | How often the library list is rebuilt. |
| `BIJOU_POSTER_WIDTH` | `900` | Plex resizes posters to this before sending. |
| `BIJOU_ART_CACHE_MB` | `96` | In-memory poster cache. |
| `BIJOU_BIND` | `0.0.0.0` | |
| `BIJOU_PORT` | `8080` | |
| `BIJOU_SETUP` | `1` | Serve the `/setup` token helper. `0` removes it. |

## How it works

```
Plex  ──poll every 3s──▶  bijou.py  ──cached JSON──▶  browser
                              │
                              └── posters, resized by Plex, held in memory
```

Two background threads keep the session state and the library list fresh. The
browser only ever reads cached values, so **Plex sees one small request every
three seconds** regardless of how many displays are pointed at it.

Posters are proxied and resized by Plex's own transcoder, then cached in
memory. The token never reaches the browser, and a kiosk restart is instant.

If Plex goes away the current poster stays up and the library list is kept.
After a minute of silence the display falls back to Coming Soon rather than
leaving "Now Showing" on a film that ended, and a small line appears under the
case. It recovers on its own.

### Endpoints

| Route | Returns |
| --- | --- |
| `/` | The display |
| `/api/state` | What's playing, if anything |
| `/api/queue` | The coming-soon list, plus timings |
| `/api/art?k=` | A poster, proxied and cached |
| `/healthz` | `{"ok": true, "queue": 412, "playing": false, "version": "1.0.0"}` |
| `/setup` | The token helper, unless `BIJOU_SETUP=0` |

## Running offline

The page pulls two webfonts from Google. To cut that dependency see
[`app/static/fonts/README.txt`](app/static/fonts/README.txt) — drop two woff2
files in and uncomment a block in `index.html`. Without them it falls back to
condensed system fonts.

## Security notes

This is built for a LAN. `bijou.py` is a plain `http.server` with no auth —
fine for a kiosk on a home network, not something to expose to the internet.

- The Plex token stays server-side; it's never in page source or a browser URL.
- `/setup` drives its own Plex login and never discloses the running config, so
  someone else on the LAN loading it learns nothing about your setup — they'd
  only get a token for their own account. It still shows *their* token in a
  browser, so on an untrusted network set `BIJOU_SETUP=0`.
- Artwork paths are pinned to `/library/...` with no `..`, since they get
  forwarded to Plex with the token attached.
- `.env` and `poster.env` are gitignored, and CI fails the build if a token
  looks committed. **Rotate your token if one ever lands in a commit** — git
  history keeps it even after you delete the file.

## Upgrading from an earlier install

If you ran this when it was called `poster-case`, the rename touched paths,
the unit name, the service user and the environment variables.

```bash
sudo systemctl disable --now poster poster-kiosk
sudo cp /etc/poster-case.env /etc/bijou.env        # keep your settings
sudo sed -i 's/^POSTER_WIDTH=/BIJOU_POSTER_WIDTH=/; s/^POSTER_/BIJOU_/' /etc/bijou.env
sudo ./deploy/install.sh
sudo cp deploy/bijou-kiosk.service /etc/systemd/system/   # if you run the kiosk
sudo systemctl daemon-reload && sudo systemctl enable --now bijou bijou-kiosk

# once it's confirmed working
sudo rm -rf /opt/poster-case /etc/poster-case.env
sudo rm -f /etc/systemd/system/poster.service /etc/systemd/system/poster-kiosk.service
sudo userdel poster
```
